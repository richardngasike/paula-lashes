# Paula Lashes

Next.js (App Router) website for Paula Lashes, Eyelash & Nail Salon in Ruaka, Kenya.

## Run

```bash
npm install
npm run dev
```

Open http://localhost:3000

## Structure

- `app/` pages: home, about, lashes, nails, pricing, gallery, book, contact
- `app/globals.css` all styling (plain CSS)
- `components/` shared UI
- `data/site.js` business info, services, prices, packages, gallery, FAQs, testimonials
- `public/` images (see `public/IMAGES.md` for the full list of file names)

## Editing content

- Prices, services and packages: `data/site.js`
- Social links and domain: `site.socials` and `site.url` in `data/site.js`
- Testimonials: replace placeholder entries in `data/site.js`
